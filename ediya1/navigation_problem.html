반응형 네비게이션 문제 해결

이 페이지는 반응형 네비게이션 구현 연습을 위한 문제입니다.

문제 목록:

  1. 문제 1: 햄버거 버튼이 PC 화면에서도 보입니다. PC 화면(1025px 이상)에서는 숨겨야 합니다.
  2. 문제 2: PC 네비게이션이 모바일에서도 보입니다. 모바일 화면(1024px 이하)에서는 사이드 메뉴로 전환해야 합니다.
  3. 문제 3: 모바일 반응형 스타일이 누락되었습니다. 미디어 쿼리를 완성하여 모바일 네비게이션을 구현하세요.
  4. 문제 4: JavaScript 기능이 없습니다. 햄버거 버튼 클릭 시 메뉴가 열리고 닫히는 기능을 구현하세요.

요구사항:

  • PC 화면(1025px 이상): 가로 네비게이션 메뉴 표시, 햄버거 버튼 숨김
  • 모바일 화면(1024px 이하): 햄버거 버튼 표시, 사이드 메뉴(오른쪽에서 슬라이드)
  • 서브메뉴는 아코디언 형태로 동작 (클릭 시 열림/닫힘)
  • 메뉴 열림 시 배경 스크롤 방지
  • ESC 키로 메뉴 닫기

테스트 방법:

브라우저 개발자 도구(F12)를 열고 디바이스 모드로 전환하여 다양한 화면 크기에서 테스트하세요.
