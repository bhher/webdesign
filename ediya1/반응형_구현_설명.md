## 1. HTML 구조

### 1.1 메타 태그 설정
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
- **목적**: 모바일 기기에서 올바른 뷰포트 설정
- **width=device-width**: 기기의 실제 너비에 맞춤
- **initial-scale=1.0**: 초기 확대/축소 비율 1:1

### 1.2 반응형 네비게이션 구조

#### 햄버거 버튼 (모바일용)
```html
<button class="mobile-menu-toggle" aria-label="메뉴 열기" aria-expanded="false">
    <span class="hamburger-line"></span>
    <span class="hamburger-line"></span>
    <span class="hamburger-line"></span>
</button>
```
- **역할**: 모바일에서 네비게이션 메뉴를 열고 닫는 토글 버튼
- **위치**: 우측 상단 (`right: 20px`)
- **접근성**: `aria-label`, `aria-expanded` 속성으로 스크린 리더 지원
- **구조**: 3개의 선으로 구성된 햄버거 아이콘
- **애니메이션**: 클릭 시 대칭적인 X 모양으로 변환

#### 네비게이션 메뉴
```html
<nav class="main-navigation" aria-label="주 메뉴">
    <ul class="gnb">
        <li class="menu-item has-submenu">
            <a href="#" class="menu-link">원두</a>
            <button class="submenu-toggle" aria-expanded="false">
                <span class="icon-arrow"></span>
            </button>
            <ul class="submenu">
                <li><a href="#">이디야 블렌드</a></li>
                <li><a href="#">품질</a></li>
            </ul>
        </li>
        <!-- ... -->
    </ul>
    <div class="shadow"></div>
</nav>
```

**주요 클래스 설명:**
- `.main-navigation`: 네비게이션 컨테이너
- `.gnb`: Global Navigation Bar (주 메뉴 리스트)
- `.menu-item`: 각 메뉴 아이템
- `.has-submenu`: 서브메뉴가 있는 메뉴 아이템
- `.menu-link`: 메뉴 링크
- `.submenu-toggle`: 모바일에서 서브메뉴를 열고 닫는 버튼
- `.submenu`: 서브메뉴 리스트
- `.shadow`: PC에서 드롭다운 메뉴의 그림자 효과

### 1.3 시맨틱 HTML 태그 사용
- `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>` 사용
- 검색 엔진 최적화(SEO) 및 접근성 향상

## 2. CSS 반응형 구현

### 2.1 기본 레이아웃 설정

#### Flexbox를 이용한 Sticky Footer
```css
html, body {
    height: 100%;
}

body {
    display: flex;
    flex-direction: column;
    min-height: 100vh;
}

.main {
    flex: 1;  /* 남은 공간을 모두 차지 */
}

footer {
    margin-top: auto;
    order: 999;  /* 항상 맨 아래에 위치 */
}
```
- **목적**: 콘텐츠가 적어도 footer가 항상 화면 하단에 위치
- **원리**: `flex: 1`로 main이 남은 공간을 차지하고, footer는 `margin-top: auto`로 밀어냄

### 2.2 PC 네비게이션 (기본 스타일)

#### Float 기반 레이아웃
```css
.main-navigation > .gnb {
    width: 1200px;
    margin: 0 auto;
}

.main-navigation .gnb > .menu-item {
    position: relative;
    float: left;
    width: 14.7%;
}

.main-navigation .gnb > .menu-item:nth-child(2) {
    width: 10%;  /* "메뉴" 항목만 더 좁게 */
}
```

#### 호버 효과
```css
.main-navigation .menu-link::after {
    content: '';
    position: absolute;
    left: 0;
    bottom: 8px;
    width: 100%;
    height: 3px;
    background-color: #202023;
    transform: scale(0, 1);  /* 처음에는 가로로 0 */
    transition: all 0.3s;
}

.main-navigation .menu-item:hover .menu-link::after {
    transform: scale(1, 1);  /* 호버 시 가로로 100% */
}
```

#### 서브메뉴 드롭다운 (Height 기반)
```css
.main-navigation .submenu {
    position: absolute;
    height: 0;  /* 기본적으로 숨김 */
    width: 100%;
    overflow: hidden;
    transition: all 0.3s;
}

.main-navigation .gnb:hover .submenu {
    height: 250px;  /* 호버 시 높이 확장 */
}
```
- **원리**: `height: 0`에서 `height: 250px`로 전환하여 자연스러운 슬라이드 효과
- **overflow: hidden**: 높이가 0일 때 내용이 보이지 않도록 함

## 3. jQuery 인터랙션

### 3.1 모바일 메뉴 토글 기능

#### 메뉴 열기/닫기 함수
```javascript
var $mobileToggle = $('.mobile-menu-toggle');
var $navigation = $('.main-navigation');
var $body = $('body');

// 메뉴 열기
function openMobileMenu() {
    $mobileToggle.addClass('active');
    $mobileToggle[0].setAttribute('aria-expanded', 'true');
    $navigation.addClass('active');
    $body.css('overflow', 'hidden');  // 배경 스크롤 방지
}

// 메뉴 닫기
function closeMobileMenu() {
    $mobileToggle.removeClass('active');
    $mobileToggle[0].setAttribute('aria-expanded', 'false');
    $navigation.removeClass('active');
    $body.css('overflow', '');  // 스크롤 복원
    
    // 모든 아코디언 메뉴 닫기
    $('.menu-item').removeClass('active');
    $('.submenu-toggle').each(function() {
        this.setAttribute('aria-expanded', 'false');
    });
}
```

#### 햄버거 버튼 클릭 이벤트
```javascript
$mobileToggle.off('click').on('click', function(e) {
    e.preventDefault();
    e.stopPropagation();
    e.stopImmediatePropagation();
    
    var $this = $(this);
    var isActive = $this.hasClass('active');
    
    if (isActive) {
        closeMobileMenu();
    } else {
        openMobileMenu();
    }
    
    return false;
});
```
- **`.off('click')`**: 중복 이벤트 바인딩 방지
- **`stopImmediatePropagation()`**: 다른 이벤트 핸들러 실행 차단

#### ESC 키로 메뉴 닫기
```javascript
$(document).on('keydown', function(e) {
    if (e.key === 'Escape' && $mobileToggle.hasClass('active')) {
        closeMobileMenu();
    }
});
```

### 3.2 아코디언 메뉴 기능

#### 서브메뉴 토글 버튼 클릭
```javascript
$('.submenu-toggle').on('click', function(e) {
    e.preventDefault();
    e.stopPropagation();
    
    var $toggle = $(this);
    var toggleEl = this;
    var $menuItem = $toggle.closest('.menu-item');
    var isExpanded = toggleEl.getAttribute('aria-expanded') === 'true';
    
    // 다른 메뉴 아이템들 닫기 (하나만 열리도록)
    $('.menu-item').not($menuItem).removeClass('active');
    $('.submenu-toggle').not($toggle).each(function() {
        this.setAttribute('aria-expanded', 'false');
    });
    
    if (isExpanded) {
        // 현재 메뉴 닫기
        $menuItem.removeClass('active');
        toggleEl.setAttribute('aria-expanded', 'false');
    } else {
        // 현재 메뉴 열기
        $menuItem.addClass('active');
        toggleEl.setAttribute('aria-expanded', 'true');
    }
});
```

**동작 원리:**
1. 클릭한 메뉴 아이템의 `active` 클래스 토글
2. 다른 모든 메뉴 아이템의 `active` 클래스 제거 (하나만 열리도록)
3. `aria-expanded` 속성 업데이트 (접근성)

#### 메뉴 링크 클릭 시 서브메뉴 토글
```javascript
$('.menu-link').on('click', function(e) {
    const $menuItem = $(this).closest('.menu-item');
    const hasSubmenu = $menuItem.hasClass('has-submenu');
    
    // 모바일에서만 동작
    if ($(window).width() <= 1024 && hasSubmenu) {
        e.preventDefault();  // 링크 이동 방지
        const $toggle = $menuItem.find('.submenu-toggle');
        $toggle.trigger('click');  // 토글 버튼 클릭 시뮬레이션
    }
});
```

### 3.3 윈도우 리사이즈 처리

```javascript
let resizeTimer;
$(window).on('resize', function() {
    clearTimeout(resizeTimer);
    resizeTimer = setTimeout(function() {
        // PC 사이즈로 변경 시 모바일 메뉴 닫기
        if ($(window).width() > 1024) {
            closeMobileMenu();
        }
    }, 250);
});
```
- **Debouncing**: 리사이즈 이벤트가 너무 자주 발생하는 것을 방지
- **목적**: 화면 크기가 PC로 변경되면 모바일 메뉴 자동 닫기

### 3.4 접근성 개선

#### 키보드 포커스 처리

```javascript
    $(this).css('outline', '2px solid #003f8c');

    $(this).css('outline', 'none');

```

## 4. 반응형 브레이크포인트

### 4.1 주요 브레이크포인트

| 화면 크기 | 브레이크포인트 | 주요 변경 사항 |
|----------|--------------|---------------|
| **PC** | `> 1024px` | 가로 네비게이션, Float 레이아웃, 드롭다운 메뉴 |
| **태블릿** | `≤ 1024px` | 햄버거 메뉴 표시, 모바일 네비게이션 활성화 |
| **모바일** | `≤ 768px` | 섹션 중앙 정렬, 이미지/텍스트 크기 축소 |

### 4.2 반응형 전략

1. **Mobile First vs Desktop First**
   - 현재 구현: **Desktop First** (PC 스타일을 기본으로, 모바일은 미디어 쿼리로 오버라이드)
   - 이유: 기존 PC 사이트를 모바일로 확장하는 구조

2. **Flexible Layout**
   - PC: Float 기반 고정 너비 (`width: 14.7%`)
   - 모바일: Flexbox 기반 유연한 레이아웃 (`flex-direction: column`)

3. **Progressive Enhancement**
   - 기본 HTML 구조는 모든 기기에서 동일
   - CSS와 JavaScript로 반응형 기능 추가
   - JavaScript 비활성화 시에도 기본 네비게이션 작동

### 4.3 성능 최적화

1. **CSS Transition 사용**
   - 하드웨어 가속을 활용한 부드러운 애니메이션
   - `transform`, `opacity` 속성 활용

2. **이벤트 최적화**
   - Debouncing으로 리사이즈 이벤트 최적화
   - `.off().on()` 패턴으로 중복 바인딩 방지

3. **접근성 고려**
   - ARIA 속성으로 스크린 리더 지원
   - 키보드 네비게이션 지원
   - 포커스 관리

## 5. 주요 특징 요약

### ✅ PC 네비게이션
- Float 기반 가로 레이아웃
- 마우스 호버 시 드롭다운 메뉴 (Height 기반 슬라이드)
- 하단 언더라인 애니메이션

### ✅ 모바일 네비게이션

## 6. 디버깅 팁

### 문제: 모바일 메뉴가 열리지 않음
- **확인 사항**:
  1. `.mobile-menu-toggle`의 `display` 속성 확인
  2. `z-index` 값 확인 (다른 요소에 가려지지 않는지)
  3. JavaScript 이벤트 바인딩 확인 (콘솔 에러 확인)

### 문제: 아코디언 메뉴가 여러 개 열림
- **해결**: `$('.menu-item').not($menuItem).removeClass('active')` 코드 확인

### 문제: PC에서 서브메뉴가 보이지 않음
- **확인 사항**:
  1. `.main-navigation .gnb:hover .submenu` CSS 규칙 확인
  2. `height: 0`에서 `height: 250px`로 전환되는지 확인
