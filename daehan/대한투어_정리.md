# 대한투어 사이트 정리 (웹디자인기능사)

## 1. 폴더/파일 구성

### 핵심 파일
- **`index.html`**: 대한투어 메인 페이지
- **`css/style.css`**: 레이아웃(1200px), 드롭다운 메뉴, 세로(상하) 슬라이드 + pager, 공지/갤러리/바로가기, 푸터, 팝업 스타일
- **`js/script.js`**: 전체메뉴 드롭다운, pager 클릭 슬라이드 전환(상하), 팝업 열기/닫기
- **`js/jquery-1.12.3.js`**: jQuery v1.12.3

### 주요 이미지 (마크업/스타일에서 확인됨)
- 로고: `images/logo.png`
- 슬라이드: `images/slide1.jpg`, `images/slide2.jpg`, `images/slide3.jpg`
- 갤러리(배경): `images/gallery1.jpg`, `images/gallery2.jpg`, `images/gallery3.jpg`
- 바로가기(배경): `images/s1.png`, `images/s2.png`, `images/s3.png`
- 푸터 아이콘
  - SNS: `images/sns1.png`, `images/sns2.png`, `images/sns3.png`
  - 패밀리 사이트: `images/family_site1.png`, `images/family_site2.png`, `images/family_site3.png`

## 2. `index.html` 구조

### 공통 설정
- `<html lang="ko">`, `<meta charset="utf-8"/>`
- 제목: `대한투어`
- 리소스 포함
  - `./js/jquery-1.12.3.js`
  - `./js/script.js`
  - `./css/style.css`

### 전체 레이아웃
- **`#wrap`**
  - `header`: 로고 + GNB(2단) + 전체배경(`.full_bg`)
  - `.img_slide`: 슬라이드 3장 + 페이지 표시(`ol.pager`)
  - `section`: 공지 / 갤러리 / 바로가기 3컬럼
  - `footer`: 카피 + SNS + 패밀리사이트
- **`.pop`**: 공지 첫 줄 클릭 시 나오는 팝업 레이어

### 헤더(`header`)
- `.h_cover` (가로 1200px, relative)
  - 로고: `h1.logo > img`
  - `.full_bg`: 2차 메뉴 배경(드롭다운 시 표시)
  - `nav > ul > li` 4개(해외여행/국내여행/제주도/렌트카)
    - 각 li 안에 2차 메뉴 `ul`

### 슬라이드(`.img_slide`)
- 슬라이드 3장: `.img_slide ul > li` (각 li 안에 이미지 + `.txt`)
- pager 3개: `ol.pager > li` (활성 클래스 `on`)
  - pager 클릭으로 특정 슬라이드로 이동

### 섹션(`section`) 3컬럼
- `article.notice`
  - `table` + `caption`
  - 첫 번째 행: `tr.t1` → 팝업 열기 트리거
- `article.gall`
  - `h3` + `.img_box` 안에 `.g1 .g2 .g3`
  - 실제 이미지는 CSS에서 `background-image`로 넣는 방식
- `article.shortcut`
  - `.s1 .s2 .s3` 각 div 안에 링크
  - 이미지 역시 CSS `background-image` 방식

### 푸터(`footer`)
- `.f_cover`
  - `.f_copy`: 저작권 문구
  - `.f_sns`: SNS 아이콘 3개 링크
  - `.f_fam`: 패밀리 사이트 아이콘 3개 링크

### 팝업(`.pop`)
- `.pop_cover`
  - `h3`: “개인정보처리방침 개정안내”
  - `pre`: 상세 안내문
  - `button`: 닫기

## 3. `css/style.css` 요약

### 헤더/GNB
- `header`: 높이 100px, 배경 `yellowgreen`
- `.h_cover`: 1200px 중앙 정렬, `position:relative`, `z-index:99`
- `nav`: 폭 500px, 오른쪽 정렬, `margin-top:50px`
- 1차 메뉴 hover: 배경 `#00c73c`, 글자색 흰색
- 2차 메뉴(`nav>ul>li>ul`)
  - `position:absolute; top:100%; left:0;`
  - 기본 `display:none`
  - hover: 배경 `#737373`, 글자색 흰색
- `.full_bg`
  - 높이 200px, 기본 `display:none`
  - 드롭다운이 열릴 때 뒤 배경으로 표시

### 슬라이드(세로 이동 방식)
- `.img_slide`: 폭 1200px, 높이 300px
- 슬라이드 `li`
  - `position:absolute; top:100%; left:0;`
  - 첫 번째만 `top:0` (처음 보여줌)
- pager
  - 원형 점(10px) 3개, 활성 `.on`은 회색(`background-color:#888`)
- `.txt`
  - 왼쪽 20%, 세로 가운데, 가운데 정렬 텍스트
  - 버튼 링크는 반투명 노란 배경 + hover 시 빨간 글자

### 섹션(공지/갤러리/바로가기)
- `section`: 폭 1200px, 높이 200px
- `article`: 400px씩 3등분(float)
- 공지: `caption`을 제목처럼 사용, `.t1`은 커서 포인터
- 갤러리/바로가기
  - 120px 박스 3개를 float로 배치
  - 이미지 대신 `background-image` + `cover`

### 푸터/팝업
- `footer`: 높이 100px, 배경 `#ccc`
- `.f_copy`(1000px) + `.f_sns`(200px) + `.f_fam`(200px) 형태로 좌우 배치
- `.pop`: fixed 전체화면 오버레이, 기본 `display:none`, `z-index:999`
- `.pop_cover`: 가운데 카드 형태(흰 배경, 패딩 30px, radius 10px)

## 4. `js/script.js` 동작 정리

### 1) GNB 드롭다운(전체 열림/닫힘)
- `nav`에 마우스 진입 시
  - `nav>ul>li>ul`(모든 2차 메뉴) + `.full_bg`를 `slideDown()`
- `nav`에서 마우스 나가면
  - 위 요소들을 `slideUp()`

### 2) pager 클릭 슬라이드(상하 전환)
- 현재 슬라이드 인덱스: `k`
- pager 클릭 시 클릭한 인덱스 `i` 계산
  - `i == k`면 종료
  - **앞으로 이동(i > k)**  
    - 새 슬라이드: `top:100% → 0`
    - 이전 슬라이드: `top:0 → -100%`
  - **뒤로 이동(i < k)**  
    - 새 슬라이드: `top:-100% → 0`
    - 이전 슬라이드: `top:0 → 100%`
  - `k = i` 갱신 + pager `on` 클래스 갱신

### 3) 팝업
- 열기: `.t1` 클릭 → `.pop` `fadeIn()`
- 닫기: `button` 클릭 → `.pop` `fadeOut()`

## 5. 웹디자인기능사 포인트
- **드롭다운 메뉴**: `nav` hover 이벤트로 2차 메뉴 전체를 한 번에 열고 닫는 패턴 + `.full_bg` 배경 처리
- **슬라이드(세로형)**: `top` 값을 `100%/-100%/0`으로 바꿔 상하 이동 애니메이션 구현 + pager로 직접 이동
- **공지 팝업**: 특정 행 클릭 → 오버레이 레이어 표시/숨김
- **이미지 처리 방식**: 슬라이드는 `<img>`, 갤러리/바로가기는 `background-image` 혼합 사용
