# EDIYA COFFEE - 반응형 네비게이션 업그레이드 버전

## 📋 프로젝트 개요

이디야 커피 웹사이트의 반응형 네비게이션과 모바일 아코디언 메뉴가 포함된 업그레이드 버전입니다.

## ✨ 주요 기능

### 🖥️ PC 버전
- **가로 네비게이션**: Flexbox를 사용한 깔끔한 레이아웃
- **드롭다운 메뉴**: 마우스 오버 시 자연스러운 fade/slide 애니메이션
- **부드러운 전환**: CSS transition을 활용한 0.3초 애니메이션
- **이디아 블루 컬러**: #003f8c 색상 적용

### 📱 모바일 버전
- **햄버거 버튼**: 우측 상단에 위치한 터치 친화적 버튼 (44x44px)
- **전체 화면 메뉴**: 슬라이드 애니메이션으로 나타나는 사이드 메뉴
- **아코디언 메뉴**: 1depth 클릭 시 2depth가 슬라이드로 펼쳐짐
- **하나만 열림**: 한 번에 하나의 메뉴만 열리는 구조
- **아이콘 회전**: 메뉴 열릴 때 화살표 아이콘이 180도 회전
- **오버레이**: 메뉴 열릴 때 배경 어둡게 처리

## 🎨 디자인 특징

- **컬러**: 이디아 블루 (#003f8c) 계열
- **레이아웃**: Flexbox 기반 반응형 디자인
- **애니메이션**: CSS transition 사용 (0.3초)
- **접근성**: ARIA 속성 (aria-expanded, aria-label) 포함
- **시맨틱 태그**: nav, ul, li 등 적절한 HTML5 태그 사용

## 🚀 사용 방법

### 1. 파일 준비
- `EDIYA` 폴더의 `images`와 `media` 폴더를 `ediya` 폴더로 복사하세요
- 또는 이미지 경로를 수정하여 사용하세요

### 2. 로컬 실행
```bash
# 프로젝트 폴더로 이동
cd ediya

# 로컬 서버 실행 (Python 예시)
python -m http.server 8000

# 브라우저에서 접속
# http://localhost:8000
```

### 3. 반응형 테스트
- 브라우저 개발자 도구(F12)에서 디바이스 모드로 테스트
- 또는 실제 모바일 기기에서 테스트

## 🎯 주요 기능 설명

### PC 네비게이션
1. **호버 효과**: 메뉴 항목에 마우스 오버 시
   - 링크 색상이 #003f8c로 변경
   - 하단에 파란색 언더라인 애니메이션
   - 서브메뉴가 fade/slide 효과로 나타남

2. **드롭다운 애니메이션**:
   - opacity: 0 → 1 (페이드)
   - transform: translateY(-10px) → translateY(0) (슬라이드)
   - transition: 0.3s ease

### 모바일 네비게이션
1. **햄버거 버튼**:
   - 클릭 시 3줄 → X자로 변환
   - 우측에서 슬라이드로 메뉴 나타남
   - 배경 오버레이 표시

2. **아코디언 메뉴**:
   - 1depth 메뉴 클릭 시 2depth 펼쳐짐
   - 화살표 아이콘 45도 → 225도 회전
   - max-height 애니메이션으로 부드러운 전환
   - 다른 메뉴 클릭 시 이전 메뉴 자동 닫힘

3. **키보드 접근성**:
   - ESC 키로 메뉴 닫기
   - 포커스 시 outline 표시
   - Tab 키로 메뉴 순회 가능

## 🔧 커스터마이징

### 색상 변경
`css/style.css` 파일에서 다음 색상을 수정하세요:
```css
/* 이디아 블루 색상 */
#003f8c  /* 메인 컬러 */
```

### 애니메이션 속도 변경
```css
/* transition 시간 조정 */
transition: all 0.3s ease;  /* 0.3초 → 원하는 시간으로 변경 */
```

### 모바일 브레이크포인트 변경
```css
/* 1024px → 원하는 크기로 변경 */
@media (max-width: 1024px) {
    /* 모바일 스타일 */
}
```

## 📱 반응형 브레이크포인트

- **PC**: 1025px 이상
- **태블릿/모바일**: 1024px 이하
- **작은 모바일**: 768px 이하

## 🐛 문제 해결

### 이미지가 표시되지 않는 경우
- `images` 폴더가 `ediya` 폴더에 있는지 확인
- 이미지 경로가 올바른지 확인

### 모바일 메뉴가 작동하지 않는 경우
- jQuery가 제대로 로드되었는지 확인
- 브라우저 콘솔에서 JavaScript 오류 확인
- 파일 경로가 올바른지 확인

### 스타일이 적용되지 않는 경우
- CSS 파일 경로 확인
- 브라우저 캐시 삭제 후 새로고침
- 개발자 도구에서 네트워크 탭 확인
