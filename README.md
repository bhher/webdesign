# 웹디자인기능사 실기 대비 첫 페이지

2026년 웹디자인개발기능사 실기 시험 대비를 위한 프로젝트 모음 첫 페이지입니다.

## 프로젝트 구조

```
웹디자인기능사-실기대비-첫페이지/
├── index.html          # 메인 페이지
├── css/
│   └── style.css       # 스타일시트
└── README.md           # 프로젝트 설명
```

## 주요 기능

### 1. 헤더 영역
- 로고 및 타이틀
- 네비게이션 메뉴 (프로젝트, 소개, 문의)
- 그라데이션 배경

### 2. 메인 비주얼
- 히어로 섹션
- 그라데이션 배경
- 타이틀 및 설명 텍스트

### 3. 프로젝트 그리드
- 24개 프로젝트 카드 레이아웃
- 반응형 그리드 시스템
- 호버 효과 및 애니메이션
- 각 프로젝트별 링크

### 4. 푸터
- 프로젝트 정보
- 저작권 정보

## 포함된 프로젝트

1. **JUST 쇼핑몰** - 온라인 쇼핑몰 사이트
2. **Green 복지재단** - 복지재단 홈페이지
3. **하이 글로벌 컴퓨터** - IT 기업 홈페이지
4. 프로젝트 04 ~ 24 (추가 예정)

## 사용 방법

1. `index.html` 파일을 웹 브라우저에서 열기
2. 각 프로젝트 카드를 클릭하여 해당 프로젝트로 이동
3. 네비게이션 메뉴를 통해 페이지 내 섹션 이동

## 스타일 특징

- **그라데이션 배경**: 모던한 디자인
- **카드 레이아웃**: 깔끔한 프로젝트 표시
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 지원
- **호버 효과**: 인터랙티브한 사용자 경험

## 반응형 브레이크포인트

- **데스크톱**: 1200px 이상
- **태블릿**: 768px ~ 1199px
- **모바일**: 480px ~ 767px
- **소형 모바일**: 480px 이하

## 커스터마이징

### 프로젝트 추가 방법

`index.html` 파일의 `.project_grid` 섹션에 다음 코드를 추가하세요:

```html
<div class="project_item">
	<div class="project_thumb">
		<span class="project_num">25</span>
	</div>
	<div class="project_info">
		<h3>프로젝트 이름</h3>
		<p>프로젝트 설명</p>
		<a href="프로젝트경로/index.html" target="_blank" class="btn_view">보기</a>
	</div>
</div>
```

### 색상 변경

`css/style.css` 파일에서 그라데이션 색상을 변경할 수 있습니다:

```css
/* 헤더 배경 */
background:linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* 메인 비주얼 배경 */
background:linear-gradient(135deg, #f093fb 0%, #f5576c 100%);
```
